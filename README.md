Estudante de Análise e Desenvolvimento de Sistemas (ADS) com foco na construção de soluções que integram arquitetura de software, automação de processos, acessibilidade e cibersegurança. Busco aplicar a tecnologia como ferramenta estratégica para resolver problemas reais, alinhando o desenvolvimento de aplicações ao compliance de proteção de dados (**LGPD by Design**) e boas práticas de engenharia.

Seja na criação de utilitários nativos de alta performance para Windows ou na arquitetura de plataformas web resilientes, meu objetivo é entregar software limpo, escalável e com superfície de ataque controlada.

### Projetos em Destaque

#### [Bitshift](https://github.com/Alyson256/Vantege-OS)
Utilitário nativo de otimização, gerenciamento de energia e telemetria de hardware para Windows 10/11.
- **Arquitetura:** Interface gráfica nativa em **C# / .NET (WPF/XAML)** com suporte bilíngue (PT/EN), leitura de sensores via WMI e gerenciamento seguro de planos de energia (`powercfg`) e serviços do sistema.
- **Segurança & Transparência:** Geração e visualização prévia de scripts reversíveis (`.BAT`), criação automática de Pontos de Restauração antes de alterações no Registro e zero telemetria invasiva.
- **Status:** Em desenvolvimento ativo (integração da camada de telemetria e rotinas de limpeza em C#).
